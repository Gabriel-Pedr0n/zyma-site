Política de Privacidade - ZYMA

Última atualização: 18 de novembro de 2026.

O que é o ZYMA

O ZYMA é uma ferramenta de uso pessoal, operada apenas pelo seu próprio desenvolvedor. Ela não é distribuída a terceiros.

Quais dados acessa

Com a autorização do dono da conta Google, o ZYMA acessa o Google Drive dessa conta somente para: (1) ler os vídeos da pasta de entrada indicada, (2) gravar os vídeos finais e arquivos de apoio (textos e controle de processamento) na pasta de saída indicada.

Como os dados são usados

Os arquivos são usados exclusivamente para gerar os vídeos finais. O áudio dos vídeos pode ser enviado a serviços de transcrição e de voz (ElevenLabs) e o texto resultante a um serviço de linguagem (Anthropic) apenas para produzir a narração e as legendas.

Compartilhamento e armazenamento

O ZYMA não vende, não compartilha e não publica dados do Google Drive com terceiros, além dos serviços técnicos citados acima. Os arquivos temporários são apagados ao final de cada execução. A credencial de acesso fica armazenada de forma segura no ambiente de execução do desenvolvedor.

Uso de dados da API do Google

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
